# Sili-Tubig: Task Avenue — User Guide

## Install
- **Android:** copy `SiliTubig_TaskAvenue.apk` to your phone, open it, and allow
  "install unknown apps" if asked. Hold the phone sideways.
- **PC:** open the project folder in Godot 4.7 and press F5.

## Start
1. Type your name (up to 16 letters) on the title screen.
2. Press **PLAY**:
   - **SOLO VS BOT:** you are the Tubig. 4 rounds from Easy to Labuyo (1–3 bots).
   - **HOST GAME:** start a LAN game; your IP is shown on the chalkboard.
   - **JOIN GAME:** tap JOIN next to a game, or type the host's IP.
   Everyone must be on the same Wi-Fi or phone hotspot.

## Goal
- **Tubig:** answer the goal number of questions ("?" scrolls) before time runs out.
- **Sili:** freeze every Tubig at the same time, or survive until time runs out.

## Controls

| Action | Keyboard | Phone |
|---|---|---|
| Move | W A S D / arrows | Drag on the right half of the screen |
| Sprint | Shift / Space | Hold RUN (bottom left) |
| Use a power-up station | E | Tap USE (appears next to a station) |
| Answer | 1–4 or click | Tap |
| Ask a teammate for help | H | Tap the button |
| Pause (host) | Esc | Pause button (top right) or Back |

## Power-ups (new spots every round)
- **Halo-Halo coolers** (Tubig): Yelo Shield for 10 s. A Sili who tags you is extinguished.
- **Bicol Express peppers** (Sili): solve a bugtong for Extra Anghang (faster, wider reach).
- **Kalamansi gates** (anyone): answer to squeeze through a shortcut; a wrong answer slows you.

## Frozen?
A teammate touches you and answers a question (**Buhos-Tubig**). If nobody can help, answer
2 hard questions in a row to thaw yourself (**Huling Hirit**).

## Settings (gear button)
Music and sound volume, touch controls, vibration, Show FPS, and **Reset my data**
(tap twice), which clears your name, settings, solo progress and this phone's leaderboard.

## Troubleshooting
- **Can't find the game in JOIN:** use a phone hotspot; type the IP shown in the host's window.
- **"Could not connect":** check that both devices are on the same network and the IP is right.
- **"The leaderboard file was damaged or edited":** the board was reset to protect it.
